# Rock Paper Scissors Game

A simple, interactive web-based **Rock Paper Scissors** game built using HTML, CSS, and JavaScript. This project allows users to play against the computer, featuring a responsive design and smooth game logic.

## Features
- **Interactive Gameplay:** Select your move (Rock, Paper, or Scissors) and play against the computer.
- **Responsive UI:** Designed with modern CSS for a clean look on all devices.
- **Game Logic:** Dynamic score tracking and winner declaration[cite: 1].
